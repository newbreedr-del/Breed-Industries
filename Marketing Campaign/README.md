## 🎨 Converting the SVG posters

The poster designs are SVG files so they scale to any size, print or screen, with zero quality loss. To export to PNG/JPG for Instagram or print:

- **Free, in-browser:** [cloudconvert.com](https://cloudconvert.com/svg-to-png) or [svgtopng.com](https://svgtopng.com)
- **Figma:** drag the SVG into a frame, then Export → PNG @1x or @2x
- **Illustrator / Inkscape:** open the SVG and File → Export As → PNG
- **macOS quick:** open in Preview → Export → PNG, set resolution to 300dpi for print

The A3 print poster (`09-A3-Print-Poster.svg`) is sized 2480×3508 at 300dpi, ready for any print shop.
